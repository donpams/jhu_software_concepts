Grad Cafe Analytics
===================

A small, tested service that scrapes self-reported graduate-admissions results
from Grad Cafe, cleans and standardizes them, stores them in PostgreSQL, and
serves an analysis page with **Pull Data** and **Update Analysis** actions.

This documentation covers how to set the project up, how the pieces fit
together, the API of every module, and how the automated test suite works.
